## O que é isto

Exercícios do curso de analista de dados da **EBAC**, feitos pelo Gabriel em 2022. Python,
analytics, machine learning, SQL e cloud, um diretório por trilha.

**É registro histórico de aprendizado, não software mantido.** O último commit é de dezembro
de 2022. É um dos dois repositórios públicos da conta.

## Regras que não se negociam

1. **Não refatorar exercício antigo.** O valor deste repositório é mostrar o que foi feito
   naquele momento, com o conhecimento daquele momento. Código "melhorado" por IA quatro anos
   depois apaga exatamente isso.
2. **Não "corrigir" solução de exercício.** Se estava errado, estava errado, e o registro é
   honesto.
3. **Não adicionar dependência, CI, lint, formatter ou estrutura de projeto.** São notebooks
   e scripts de curso.
4. **O README é um checklist de progresso do curso.** Os módulos desmarcados nunca foram
   feitos; não marque nada, e não invente conclusão de módulo.
5. **Repositório público.** Nada de dado pessoal, credencial ou arquivo de terceiro entra
   aqui, nem num notebook de exemplo.
